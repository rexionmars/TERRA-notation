# AGENTS.md

Instructions for coding agents working in this repository. What the application does is in
[README.md](README.md), and how it is built and why is in
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Read the section of the architecture notes
for the part you are about to change.

## The project

TERRA Notation is a Wails v2 desktop application with one user and one machine, and no
server. It annotates the points of a GeoPackage against current imagery and keeps the
answers and screenshots in a project folder.

| Path | What it is |
|---|---|
| `*.go` at the root | the Wails application; `app_<subject>.go` holds the methods bound to the frontend |
| `internal/gpkg` | GeoPackage reading (GP header, WKB, SRS, R-tree) and writing |
| `internal/annotation` | the project folder: settings, answers, history, screenshots |
| `internal/exports` | CSV, GeoPackage and HTML exports |
| `frontend/src/lib` | logic without React, tested with Vitest beside each module |
| `frontend/src/components`, `frontend/src/pages` | the interface |
| `frontend/wailsjs` | generated by `wails build` / `wails dev`; never edited by hand |

## Rules the data depends on

These hold for every change. A change that needs to break one is a change to the project
format and is discussed before any code is written.

- The source GeoPackage is opened read-only and never written.
- `annotation_history` only receives rows. Its triggers stay, and no code path updates or
  deletes a row of it.
- `first_category` is set once and never overwritten.
- A screenshot file is never overwritten or deleted. Replacing or removing one sets
  `removed_at`.
- A category used by a saved answer cannot be removed.
- Every export goes to a new folder.
- Shipping code never generates data to stand in for a result it could not get. A missing
  value is shown as missing, with the reason.

- `frontend/src/lib/maplibreWorker.ts` stays imported first in `main.tsx`. Without it no
  GeoJSON layer draws, the map never becomes idle, a map capture waits forever, and
  nothing says why (see "MapLibre's worker" in the architecture notes).

## Contracts across languages

- `frontend/src/lib/types.ts` mirrors, by hand, the JSON tags of the Go structs the bound
  methods return. A change to a tag changes both sides in the same commit.
  `frontend/src/lib/api.ts` is the only module that casts the generated bindings.
- After changing a bound method's signature, regenerate the bindings with
  `wails generate module` (or a build), and commit `frontend/wailsjs` with the change.
- A Go type that crosses to the frontend must not be named `Record`, and a Go package
  must not be named after a TypeScript reserved word. The generated namespace writes Go
  maps as `Record<K, V>`, which a class named `Record` would shadow, and it names each
  namespace after the package. See "Cross-language contracts" in the architecture notes.

## Conventions

- Code, comments, documentation, commit messages and the interface are in English
  (American spelling).
- The interface follows TERRA's design system: its tokens, type scale, buttons and icons,
  copied value for value (see "The interface's design" in the architecture notes). A
  token is changed in TERRA first and copied here; a new control is built from the
  primitives in `components/ui.tsx`.
- A name says what a thing is. Packages and folders are named for their subject, never
  `util`, `helpers` or `common`.
- A comment states the rule as it stands and why it holds: a constraint, a measured value,
  the failure a shape prevents. The story of how it was found belongs in the commit message.
- Go errors start in lower case, carry no final punctuation, name the operation, and wrap
  with `%w`. They are compared with `errors.Is` and `errors.As`.
- Text a user reads says what happened and what to do about it. Quantities carry SI
  units; negative numbers shown to people use the typographic minus.
- TypeScript runs in strict mode without `any`. Components are function declarations with
  named exports.
- Invisible or look-alike characters in string literals (U+2212 minus, narrow or
  non-breaking spaces, combining marks) are written as `\u` escapes. In JSX text and Go
  raw strings an escape is not interpreted, so visible symbols such as `⌘` and `·` are
  written as they are there.
- Tests are named for the behaviour they guard, as a sentence, and build their fixtures
  inside the test. Go tests use only the standard `testing` package and `t.TempDir`.

## Checks

Run the checks for every area you touched. Each must pass before you report the work as
done, and the report says what you ran and what it printed.

From the root (on a fresh clone, run `npm install && npm run build` in `frontend/` first,
because `main.go` embeds `frontend/dist`):

```sh
gofmt -l .                # must print nothing
go vet ./...
go test -race ./...
```

From `frontend/`:

```sh
npm run check:format      # npm run format writes what this compares against
npx tsc --noEmit
npm test
```

The application: `wails build` at the root produces `build/bin/TERRA Notation.app`.

## Commits

- One subject per commit, in the form `type(scope): what is now true`, for example
  `feat(map): a pasted location centres the map and lists the nearest records`.
- The body says why, and what was measured or checked.
- A refactor that changes no behaviour goes in its own commit.
- Commit explicit paths (`git commit -- <paths>`), never `git add -A`.
